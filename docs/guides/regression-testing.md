# 회귀 테스트 시나리오

배포 전후로 반복 실행하는 수동/Playwright MCP 회귀 테스트 체크리스트입니다. Task 018-1(관리자 플로우
통합 테스트)에서 정리한 시나리오를 배포마다 재사용할 수 있는 형태로 옮겼습니다. "어떻게 배포하는가"는
[`deployment.md`](./deployment.md)를, "무엇을 확인하는가"는 이 문서를 참고하세요.

## 공개 사용자 여정 (V1)

- [ ] 홈(`/`) 진입 → 인보이스 ID 입력 폼 정상 렌더링
- [ ] 데모 링크(`INV-2026-001 보기` 등) 또는 직접 ID 입력 → 인보이스 상세 페이지로 정상 이동
- [ ] 상세 페이지: 발행자/클라이언트/상품 테이블/합계가 Notion 원본과 일치
- [ ] PDF 다운로드 버튼 클릭 → 파일 정상 다운로드, 한글 정상 렌더링(폰트 임베드 확인)
- [ ] 잘못된 ID 또는 존재하지 않는 ID 접근 → `not-found` 정상 표시, 내부 오류 메시지 미노출
- [ ] 모바일(375)·태블릿(768)·데스크톱(1280) 반응형 정상
- [ ] 다크모드/라이트모드/시스템 테마 정상, 새로고침 후 테마 유지
- [ ] 콘솔 에러 0건

## 관리자 여정 (V2)

> 배포 전 [`deployment.md`](./deployment.md)의 "관리자 영역 배포 체크리스트"(인증 선행 조건 등)를
> 먼저 확인하세요.

- [ ] `/admin` 진입 → 실제 Notion 데이터가 발행일 내림차순으로 표시, 건수·번호·클라이언트·총금액이
      Notion 원본과 일치
- [ ] 상태 배지(대기/발송/확인함/완료)와 "기한 지남" 배지가 올바르게 매핑됨
- [ ] "링크 복사" 클릭 → 클립보드 값이 `{배포 도메인}/invoice/{id}`와 정확히 일치, 토스트 표시
- [ ] 클립보드 API 미지원/실패 상황에서 폴백 입력창으로 URL 확인 가능
- [ ] 견적서 번호 또는 "새 탭에서 열기" 클릭 → 새 탭에서 공개 상세 페이지가 목록과 동일한 데이터로
      렌더링
- [ ] 모바일 뷰포트에서 액션이 드롭다운 메뉴("링크 복사"·"새 탭에서 열기")로 접혀 표시되고 정상 동작
- [ ] 데이터 0건일 때 빈 상태 UI, Notion 조회 실패 시 오류 폴백 UI(내부 정보 비노출) 정상 표시
- [ ] `/admin/*` 미매치 경로 접근 시 관리자 전용 404 표시
- [ ] 모바일(375)·태블릿(768)·데스크톱(1280) 반응형 정상
- [ ] 다크모드/라이트모드 정상, 테마 토글이 헤더에서 승계되어 동작
- [ ] 배포된 페이지 소스에 `robots: noindex, nofollow`가 적용되어 있음(검색 노출 차단)
- [ ] "인증 미적용" 안내 배너가 노출됨(Task 018 완료 전까지)
- [ ] 콘솔 에러 0건

## 통합 여정

- [ ] `/admin` → 링크 복사 → 새 탭 공개 상세 확인 → PDF 다운로드 → 관리자 탭 복귀까지 끊김 없이 진행
- [ ] 관리자 기능 추가 후에도 공개 여정(홈 → ID 입력 → 상세 → PDF)이 동일하게 동작(회귀 없음)
